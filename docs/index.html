局域网文件投递 · macOS / Windows

把文件
递过去。

电脑和手机在同一个 Wi-Fi 下，扫码就能互传。
手机不用装 App，文件不经过任何服务器。

下载 macOS 版 Apple 芯片 · 37MB · 内置运行时 下载 Windows 版 x64 · 33MB · 免安装

解压即用。首次打开：macOS 右键 →「打开」，Windows 可能提示「仍要运行」。
Intel Mac 请用 x64 版本。

01

手机零安装

浏览器扫码就是传输页。加到主屏幕之后，它就是一个图标，不用装任何 App。

02

不压缩，不限大小

局域网直连，照片、视频、安装包原样过去。没有大小限制，也不会上传到任何云端。

03

拖一下就发

把文件拖到程序坞或桌面上的「手递」图标上，手机上点一下 ↓ 就能拿到。

三步

  1. 打开电脑上的「手递」浏览器里出现传输页和二维码
  2. 手机扫码相机扫一下，网页直接打开
  3. 电脑点「允许」这台手机被记住，以后免确认

Security

陌生人连不进来

同一个 Wi-Fi 下的其他设备，光知道地址是打不开的。第一次连接要在电脑上点一次「允许」，之后这台设备被记住；随时可以在电脑端撤销。

  • 删文件、打开文件夹、停止服务 —— 只有电脑自己能做
  • 二维码只是地址，不等于放行
  • 数据只在局域网内，不上云、不经第三方服务器

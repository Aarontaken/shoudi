手递 · Windows 版
=====================================

电脑和手机在同一个 Wi-Fi 下，直接递文件。
手机什么都不用装，浏览器扫码就能用。


第一次用
--------
1. 先把整个 shoudi-win 文件夹放到一个固定的地方（比如 D:\Tools\shoudi）
   —— 之后别挪它，桌面快捷方式用的是绝对路径
2. 双击  start.vbs              → 浏览器会打开传输页
3. 双击  install-shortcut.vbs   → 桌面上多一个「手递」图标（推荐）

以后点桌面上那个「手递」图标就行，没有黑窗口。

如果 Windows 弹出「已保护你的电脑」：
  点「更多信息」→「仍要运行」。这只会在第一次出现。


手机上怎么连
------------
页面上有个二维码，用手机相机扫一下，浏览器就打开了。
在浏览器菜单里选「添加到主屏幕」，以后手机点图标就能传。

传文件：
  · 手机 → 电脑：点「把文件丢进来」选文件
  · 电脑 → 手机：把文件拖进页面，或者直接拖到桌面「手递」图标上
  · 文字/链接：任意一边贴进去，另一边点「复制」


第一次运行会弹防火墙提示
------------------------
一定要选「允许访问」，并且把「专用网络」勾上。
点了取消的话，手机就连不上（本机自己还能用）。

补救办法：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙，
找到 node.exe，把「专用」勾上。


文件存在哪
----------
C:\Users\你的用户名\Downloads\LocalDrop
页面上右边的「打开文件夹」也能直接打开。


出问题了看这里
--------------
%TEMP%\shoudi-server.log

常见情况：
  · 手机打不开页面  → 多半是防火墙没放行，或者两台设备不在同一个 Wi-Fi
  · 端口被占用      → 看日志里有没有 EADDRINUSE
  · 想换端口        → 在命令提示符里：
                      set SHOUDI_PORT=9000 && wscript start.vbs


小提示
------
这个文件夹可以整个拷到别的 Windows 电脑上用，不需要装 Node.js。
